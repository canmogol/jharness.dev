The first release of JHarness: a terminal coding agent in one native executable, where the model acts only by writing JavaScript that runs in a GraalJS sandbox.

## Install

On Linux (x86-64, ARM64) or an Apple silicon Mac:

```bash
curl -fsSL https://raw.githubusercontent.com/canmogol/jharness.dev/master/scripts/install.sh | sh
```

or `brew install canmogol/jharness/jharness`. The script checks the archive's SHA-256 and installs to `~/.local/bin` without sudo. On Linux, install bubblewrap so JHarness can run processes in its sandbox (`sudo apt install bubblewrap`).

## What it does

- **Sandboxed agent code.** The model writes JavaScript that reaches files, git, builds, the network and subagents only through the `api`, in a GraalJS isolate with CPU, memory and time limits.
- **Approvals and rules.** Changes ask first, with `ask`, `accept-edits`, `plan` and `bypass` modes and saved "always" rules. The deny list keeps secrets out, and every turn can be undone with `/undo` and `/rewind`.
- **Build tools in an OS sandbox.** Maven, Gradle, npm, Go and gofmt run as JSON tool definitions you can edit, under Seatbelt on macOS and bubblewrap on Linux. They reach the network only through JHarness's egress proxy and its rules.
- **Subagents.** Foreground and background subagents, with `/agents`, `/follow`, `/switch` and `/answer`. Custom agents, hooks, slash commands, MCP servers and an optional action reviewer extend it.
- **A prompt that never blocks.** You type while the agent works, messages queue, and Esc stops a turn. The status line sits at the bottom.
- **Context and sessions.** Token counting, auto-compaction, prompt caching, `@file` mentions, `--resume` and `--fork`, and usage and cost tracking.
- **Headless and the viewer.** `-p` with text, JSON or stream-JSON output for scripts and CI; `jharness view` shows a session in the browser, read-only.

## Files

`jharness-linux-amd64.tar.gz`, `jharness-linux-aarch64.tar.gz`, `jharness-macos-aarch64.tar.gz`, `SHA256SUMS` and `install.sh`. Every file has a build attestation:

```bash
gh attestation verify jharness-macos-aarch64.tar.gz --repo canmogol/jharness.dev
```

## Known limits

- The macOS binary isn't code-signed or notarized yet. Installs with `install.sh` or Homebrew run it as is; a file downloaded through a browser needs `xattr -d com.apple.quarantine jharness`.
- There is no Windows build.
- `jharness update` and signed updates come later.

See `CHANGELOG.md` for every change, spec by spec.
